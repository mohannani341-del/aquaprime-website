AquaPrime Prawn Seeds — Python Flask Multi-Page Website
=========================================================

Pages:
  /             Home
  /about        About
  /why-us       Why Us
  /gallery      Gallery
  /enquiry      Enquiry
  /contact      Contact

All navigation opens in the SAME browser tab.
Each menu item loads its own Flask page instead of scrolling a single page.

Run:
  venv\Scripts\activate
  python app.py

Then open:
  http://127.0.0.1:5000

Enquiries currently print in the terminal.
